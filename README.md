# مِحراب | MIHRAB

**مِحراب** تطبيق إسلامي عربي يهدف إلى جمع مواقيت الصلاة والقرآن الكريم والأذكار والتقويم الهجري في تجربة واحدة أنيقة، مع دعم العمل دون اتصال قدر الإمكان.

> الاسم العربي المعتمد في المشروع هو **مِحراب** (وليس «ميحراب»).

## الحالة الحالية
- [x] إنشاء مشروع Android باستخدام Kotlin وJetpack Compose.
- [x] واجهة عربية أولية واتجاه RTL.
- [x] ساعة رقمية تتحدث كل ثانية.
- [x] هيكل التنقل بين أقسام التطبيق.
- [x] إعداد GitHub Actions لبناء نسخة APK تجريبية.
- [ ] ربط مواقيت الصلاة بمصدر البيانات الرسمي بعد التحقق من طريقة الوصول للبيانات.
- [ ] تحديد الموقع بإذن المستخدم مع اختيار المدينة يدوياً.
- [ ] المصحف بالرسم العثماني وتخطيط صفحات موثوق.
- [ ] الأذكار والختمة والتقويم والتنبيهات.

## التقنية
- Kotlin
- Android
- Jetpack Compose
- Gradle
- GitHub Actions

## بناء APK
كل تحديث إلى فرع `main` يشغّل سير عمل **Android APK**. بعد نجاحه، افتح تبويب **Actions** في GitHub، ثم افتح آخر تشغيل وحمّل الملف من **Artifacts** باسم `MIHRAB-debug-apk`.

## مبادئ المشروع
- لا نعرض مواقيت صلاة تقديرية على أنها مواقيت رسمية.
- لا نضيف نصوصاً قرآنية أو أحاديث قبل التحقق من صحتها ومصدرها.
- نحافظ على خصوصية الموقع، ولا نطلب إذن GPS إلا عند الحاجة وبموافقة المستخدم.
- لا نعتمد Firebase أو Supabase.
