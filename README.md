# مِحراب | MIHRAB

**مِحراب** تطبيق إسلامي عربي يهدف إلى جمع مواقيت الصلاة والقرآن الكريم والأذكار والتقويم الهجري في تجربة واحدة أنيقة، مع دعم العمل دون اتصال قدر الإمكان.

> الاسم العربي المعتمد في المشروع هو **مِحراب** (وليس «ميحراب»).

## الحالة الحالية
- [x] إنشاء مشروع Android باستخدام Kotlin وJetpack Compose.
- [x] واجهة عربية أولية واتجاه RTL.
- [x] ساعة رقمية تتحدث كل ثانية.
- [x] هيكل التنقل بين أقسام التطبيق.
- [x] صفحات تأسيسية مستقلة للصلاة والقرآن والأذكار والمزيد.
- [x] توضيح أن المواقيت والمحتوى القرآني والأذكار لن تُعرض قبل ربط مصادر موثوقة والتحقق منها.
- [x] إعداد GitHub Actions لبناء نسخة APK تجريبية.
- [ ] ربط مواقيت الصلاة بمصدر البيانات الرسمي بعد التحقق من طريقة الوصول للبيانات.
- [x] عدم عرض مواقيت تخمينية قبل التحقق من المصدر.
- [x] اختيار المدينة يدوياً وحفظها محلياً بين مرات تشغيل التطبيق.
- [ ] تحديد المدينة تلقائياً عبر GPS بإذن المستخدم.
- [ ] المصحف بالرسم العثماني وتخطيط صفحات موثوق.
- [x] مخطط ختمة محلي بخيارات 7 و15 و30 يوماً وحفظ تقدم الصفحات.
- [x] حفظ صفحة القراءة الحالية وآخر موضع محفوظ محلياً، مع التنقل بين صفحات المصحف (1–604).
- [x] عدّاد ذكر شخصي محفوظ محلياً دون تخصيص أعداد شرعية.
- [x] إضافة ذكرين للصباح والمساء مع المراجع ودرجة التصحيح وعدّادات محلية: أبي داود 5068 و5088.
- [x] إضافة أذكار بعد الصلاة: الاستغفار ثلاثاً ودعاء «اللهم أنت السلام» (صحيح مسلم 591).
- [x] إضافة التسبيح والتحميد والتكبير بعد الصلاة مع تمام المئة (صحيح مسلم 597).
- [x] عرض التاريخ الهجري بأسماء الأشهر العربية.
- [ ] الأذكار والختمة والتقويم والتنبيهات.

- الإصدار التطويري: 0.6.0 (حفظ موضع القراءة وإضافة أذكار صباح ومساء موثقة).

## اعتماد الاسم والهوية
- الاسم العربي الوحيد في واجهة التطبيق: **مِحراب**.
- يمنع استخدام كتابة «ميحراب» في النصوص العربية أو اسم التطبيق الظاهر.
- الاسم التقني للمستودع والحزمة يمكن أن يبقى `MIHRAB`.

## التقنية
- Kotlin
- Android
- Jetpack Compose
- Gradle
- GitHub Actions

## بناء APK
كل تحديث إلى فرع `main` يشغّل سير عمل **Android APK**. بعد نجاحه، افتح تبويب **Actions** في GitHub، ثم افتح آخر تشغيل وحمّل الملف من **Artifacts** باسم `MIHRAB-debug-apk`.

## مبادئ المشروع
- لا نعرض مواقيت صلاة تقديرية على أنها مواقيت رسمية.
- لا نضيف نصوصاً قرآنية أو أحاديث قبل التحقق من صحتها ومصدرها.
- نحافظ على خصوصية الموقع، ولا نطلب إذن GPS إلا عند الحاجة وبموافقة المستخدم.
- لا نعتمد Firebase أو Supabase.
